# Security Policy

## Scope

This project is a local desktop application for STM/STS data analysis.

## Data collection

By design, this application does not collect, transmit, or store user accounts, cloud telemetry, or analytics data.
Input files are selected locally by the user and outputs are written locally to user-selected paths.

## Supported versions

Security fixes are applied on the `main` branch and included in new releases/updates.

## Reporting a vulnerability

If you discover a security issue, please open a private report first:

1. Email the maintainer listed in this repository profile or open a private security advisory in GitHub.
2. Include reproduction steps, impact, and affected files/versions.
3. Do not publish proof-of-concept details until a fix is available.

We will acknowledge reports as quickly as possible and coordinate disclosure and remediation.
